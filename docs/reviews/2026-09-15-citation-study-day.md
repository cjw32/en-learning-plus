# 引用定位与学习打卡验收（2026-09-15）

## 已实现

- Coach 中 word/course 引用打开已有学习页。词条通过 `GET /api/v1/word-book/:id` 精确读取，复用来源字段授权，独立详情区展示纯文本并聚焦；不依赖第一页包含目标。课程列表滚动、聚焦、高亮指定课程。失效、无权、非法地址有状态提示，读取失败可重试；没有目标页的 grammar/exercise 不再显示空跳转按钮。
- 学习打卡表示累计学习天数，固定按北京时间划日。成功新增课程单词记录、首次保存 Coach 作答、首次持久化可靠发音结果时，在学习写事务中记录 `UserStudyDay`。用户/日期唯一键和冲突忽略保证三个入口每天合计只记一次。保存失败、取消、过期、低置信参考结果和旧请求重放不计入。
- `GET /api/v1/learn/stats` 仅使用登录令牌身份，返回 `wordNumber/dayNumber/checkedInToday/studyDate/timezone`。顶栏展示累计天数与今日勾选，在学习完成、路由变化、页面聚焦或恢复可见时刷新；拒绝旧账号的迟到响应。
- 兼容保留既有 dayNumber，不补造历史。打卡仅保存账号和日期，删除单项学习记录不减少参与天数，删除账号级联清除。Coach 写入开关关闭时不会因为只显示批改反馈而计数。

## 验证证据

- 前端单元测试：33 个文件、166 项通过，包含异步引用切换和账号隔离。
- 后端完整回归：238 个套件、1442 项通过，5 项按既有条件跳过；1 个快照通过。Redis 测试使用独立临时实例。
- 旧课程专项回归：2 项通过。
- Chromium 浏览器：5 条通过，覆盖非第一页词条、安全文本显示、失效提示、课程定位、加载失败重试以及学习后顶栏刷新。浏览器接口为合成响应，不能替代来源授权和真实模型质量验收。
- 真实本地 PostgreSQL：20 个同日并发请求只记一天、次日新增、事务回滚、账号隔离、课程跨天重放、无效保存均通过。测试账号和单词结束后删除。
- 真实本地 HTTP：匿名访问拒绝、初始状态、完成课程后的累计/今日状态、重复提交不增加、查询参数不能切换账号、空提交和失效引用拒绝均通过。
- Web 类型检查及前后端构建通过。手写文件差异检查通过；Prisma 生成文件保留生成器原有空白格式。
- 本机数据库已应用 `20260915010000_user_study_day`，业务服务和 AI 服务已加载新构建。未部署远程环境。

## 当前配置与范围边界

本机词典来源当前未通过 excerptDisplay 字段授权，真实 HTTP 词条读取返回 404 并显示不可用；本轮没有修改来源授权或伪造许可。已授权内容的精确投影和浏览器定位由确定性测试覆盖。若要在当前本机看到词条正文，仍需为具备实际许可的内容完成来源授权配置。课程定位可直接使用，不包含课程正文或购买权限绕过。

本轮不调用真实模型或 Azure，不开启 Coach live/write、韵律收费或自动掌握写回开关，不提供补签、连续天数、打卡日历或未实现来源类型的详情页。

可重复的本地验证工具：`server/tools/check-study-day-live.ts`、`server/tools/check-study-api-live.ts`；须显式 `STUDY_DAY_LIVE_CHECK=true`，并验证目标为本机 15432 数据库。测试仅清理本次创建的合成数据。

# 发音评测本机真实服务验收（2026-09-15）

范围：T119–T122 / FR-093–095，衔接 T110–T118 / FR-089–092。原 FR-001–088 保留；实现补充条款改用 FR-089–095，消除重号。用户授权完成发音评测并确认 eastasia Azure Speech Free F0；本次没有创建付费资源、切换定价层或部署公网服务。

## 已实现并接通

- 手动英文、单词本和平台 Coach 练习入口，浏览器参考发音、录音预览、提交、进度、错误恢复与真实评分。
- 真实 ffprobe/ffmpeg 校验和转码；私有 MinIO 音频存储；PostgreSQL 状态和结果；Redis 队列、额度、取消、超时和恢复。
- 总分、准确度、完整度、流利度与逐词反馈；历史分页、鉴权回放、逐词定位、仅删除录音和删除完整评测。
- Azure managed 模式明确记录底层版本未公开，不伪造供应商证明。F0 使用零单价和独立音频时长配额，不因价格为零放开无限调用。
- 默认本机额度：用户每天 300 秒、全站每天 1800 秒、全站每月 14400 秒、资源并发 1。原有请求频率和金额治理继续生效。
- 修复生产模块才暴露的问题：共享契约的 Node 构建和导出、队列 Redis 密码、可选支付凭据导致全服务无法启动、严格 API 响应被全局拦截器二次包装、Nest 将音频 Buffer JSON 化而无法播放。二进制响应改用 StreamableFile；错误仅透传通过契约验证的公开字段。

本机依赖采用独立 Docker 项目和数据卷，端口 PostgreSQL 15432、MinIO 19000/19001、Redis 16379 均仅绑定 127.0.0.1。七个已有 Prisma 迁移在新建本地数据库完成。密钥和随机连接密码仅保存在已忽略的 `server/.env`。运行和复现方式见 [运行指南](../pronunciation-runtime.md)。

## Clarifications

### Session 2026-09-09

- Q: 第一阶段采用什么浏览器支持政策、音频格式与录制边界？ → A: 支持桌面与移动端主流浏览器最近两个稳定大版本并执行运行时能力检测；接受 WebM/Opus 与 MP4/AAC，单次最多 30 秒、8 MB、最少 500 毫秒，目标最多 30 个英文词或 200 个字符，上传 30 秒超时；正式计分录音不允许暂停。
- Q: 原始录音应保存多久，用户和第三方可以如何使用？ → A: 提交前仅保存在浏览器，提交后最多临时保存 24 小时供短期重试和跨会话回放；取消或用户主动删除后立即撤销访问并在 1 小时内清除活动副本，不进入普通备份、不提供延长或永久保存；Provider 必须禁训并采用零留存。
- Q: 首发 Provider、置信度、请求限制、成本和发布门槛如何确定？ → A: 首发仅启用一个主 Provider 且不混合评分；统一可信度低于 0.60 时拒绝评测、0.60–0.79 只显示参考反馈、至少 0.80 才有学习写入资格；每用户单并发、6 次/分钟、120 次/天，单次处理 30 秒硬超时、P95 目标 15 秒；上线前批准单次、用户日、系统日和系统月预算，未知价格时关闭调用，并以安全和错误写入零容忍为发布硬门槛。

## User Scenarios & Testing _(mandatory)_

### User Story 1 - 完成一次可解释的发音评测 (Priority: P1)

已登录学习者从单词、课程、练习、具有合法来源的学习内容、Coach 推荐或合法手动输入中选择明确的目标文本，主动开启麦克风，录制单词、短语或单句，试听后提交评测。学习者看到整体表现、识别文本、准确度、完整度、流利度、可用时的语调得分，以及逐词的正确、误读、漏读、插入或不确定状态。

**Why this priority**: 这是功能的最小可用价值；没有可信、可解释的逐词反馈，就不能解决用户只听标准发音却不知道自己错在哪里的问题。

**Independent Test**: 使用一个已登录测试用户，分别朗读一个单词、一个短语和一个单句；验证三次都能从明确目标文本开始，经录音、试听、提交后得到符合统一结构的反馈，并能定位至少一种逐词状态。

**Acceptance Scenarios**:

1. **Given** 用户进入可发音练习的单词或练习页面且麦克风可用，**When** 用户主动开始、停止、试听并提交录音，**Then** 系统显示从准备录音到评测成功的完整状态，并返回结构有效的发音反馈。
2. **Given** 评测服务支持整体、准确度、完整度和流利度，**When** 返回有效结果，**Then** 所有可用评分均处于 0–100，且页面解释每项评分的学习含义。
3. **Given** 评测服务不支持语调或某个可选维度，**When** 返回结果，**Then** 该维度明确显示为“本次不可用”且数据值为空，不生成或推断虚假分数。
4. **Given** 结果包含逐词时间戳，**When** 用户选择某个词，**Then** 用户可从对应音频片段开始播放并查看该词的状态、分数与反馈。
5. **Given** 结果没有可靠时间戳，**When** 用户查看逐词反馈，**Then** 仍可查看词级状态和说明，但跳转播放功能不可用且原因明确。
6. **Given** 用户朗读带有标点、大小写、缩写、重复词或插入词的目标文本，**When** 评测完成，**Then** 页面中的每个目标词保持稳定顺序和独立身份，插入词单独标记，不因规范化而错配重复词。

### User Story 2 - 安全控制浏览器录音 (Priority: P1)

学习者在明确知情后授权麦克风，能够开始、停止、取消、删除和重新录制；录音期间可看到时长及基础音量或波形反馈，结束后可在本地试听。正式计分录音保持连续，不提供暂停；权限、设备、浏览器、网络或音频质量异常时，用户得到明确且可恢复的提示。

**Why this priority**: 音频采集是整个评测的入口，也涉及敏感数据、设备权限和大量失败边界，必须与评分能力同级交付。

**Independent Test**: 在支持、拒绝权限、无设备、录音中断、网络断开和不支持六类环境中完成状态转换测试；验证每种情况都有正确状态、资源释放和下一步操作。

**Acceptance Scenarios**:

1. **Given** 用户尚未授权麦克风，**When** 页面准备录音，**Then** 页面先说明采集目的和数据处理边界，只在用户主动操作后请求权限。
2. **Given** 用户允许麦克风访问，**When** 录音开始，**Then** 页面显示“正在录音”、计时和非语义化音量或波形反馈，不在后台静默录音。
3. **Given** 用户停止录音，**When** 音频达到有效条件，**Then** 页面进入“已完成录音”，允许本地试听、删除、重新录制或提交。
4. **Given** 用户取消录音、关闭页面或录音被系统中断，**When** 当前录音尚未提交，**Then** 页面确认可能丢失的内容，停止采集，释放麦克风和本地临时资源，不提交评测。
5. **Given** 权限被拒绝、设备不存在或浏览器不支持，**When** 用户尝试录音，**Then** 页面显示对应原因、可行的设置指引或替代路径，不把它笼统显示为评测服务失败。
6. **Given** 音频过短、过长、过大、静音或音量过低，**When** 用户停止或提交，**Then** 系统在可判定的最早阶段阻止无效评测，说明如何重录，且不消耗一次有效学习评测额度。
7. **Given** 页面处于上传或分析状态，**When** 用户取消，**Then** 页面立即显示“已取消”，系统尽可能终止尚未开始或仍可中止的后续处理，并保证不写入学习状态。

### User Story 3 - 将有效发音结果纳入学习闭环 (Priority: P1)

当评测身份、目标资源、音频与结构化结果全部有效且置信度足够时，系统把评测关联到当前用户、目标单词或练习、课程和现有学习作答记录。误读和漏读可形成发音薄弱项，并按明确规则影响掌握度与复习计划；用户能看到本次写入和计划变化。

**Why this priority**: 只有进入可靠的学习闭环，发音反馈才会持续影响个性化练习和复习，而不是一次性分数。

**Independent Test**: 对同一目标提交一次有效结果、一次重复请求、一次低置信度结果、一次取消和一次越权请求；验证只有首次有效结果写入一次，并只对当前用户产生可解释的学习状态变化。

**Acceptance Scenarios**:

1. **Given** 当前用户的评测通过全部校验且统一可信度不低于 0.80，**When** 保存完成，**Then** 评测与对应学习作答记录关联，并显示新增薄弱项、掌握度变化及下次复习时间。
2. **Given** 同一逻辑提交因双击、重试或网络重连再次到达，**When** 系统处理相同幂等意图，**Then** 返回首次结果，不重复调用计费评测、不新增学习记录、不重复调整复习计划。
3. **Given** 结果低置信度、无法识别、结构无效、评测失败或被用户取消，**When** 流程结束，**Then** 该结果可按审计需要记录终态，但不会降低掌握度或创建复习惩罚。
4. **Given** 逐词结果含误读或漏读，**When** 有效结果被保存，**Then** 只有能可靠映射到权威目标词的项才可更新为发音薄弱项，插入词和不确定词不会自动降低词汇掌握度。
5. **Given** 学习记录写入中的任一步骤失败，**When** 事务结束，**Then** 发音结果与掌握度/复习计划变化要么全部生效，要么均不生效，并向用户显示“评测完成但学习记录未更新”的可重试状态。

### User Story 4 - 从 Coach 获得后续口语练习 (Priority: P2)

学习者完成有效评测后，可以让个性化 Coach 基于结构化摘要、薄弱词和复习状态推荐重试、复习或继续学习。Coach 默认不读取原始音频，也不能绕过学习业务边界访问录音。

**Why this priority**: 这把既有 Coach 的个性化推荐能力扩展到口语练习，同时避免原始语音进入不必要的模型上下文。

**Independent Test**: 完成一条含误读和漏读的有效评测后请求推荐；验证推荐引用本次结构化结果及当前用户的学习状态，不访问音频，不混入其他用户数据。

**Acceptance Scenarios**:

1. **Given** 用户有一条有效发音评测，**When** 用户请求下一步建议，**Then** Coach 可读取最少必要的结构化摘要，并解释推荐与本次薄弱点或到期复习项的关系。
2. **Given** 评测低置信度或失败，**When** Coach 推荐下一步，**Then** 建议优先改善录音或重试，不把不可靠分数当作已确认的学习事实。
3. **Given** Prompt、模型输出或工具参数试图指定其他用户或读取原始录音，**When** 请求执行，**Then** 服务端主体不改变，越权数据不返回，录音不进入 Coach 上下文。
4. **Given** 评测目标来自 RAG 学习内容，**When** Coach 使用它继续练习，**Then** 目标内容仍保留可核验来源和访问资格；来源失效后不得继续作为权威目标文本。

### User Story 5 - 管理个人录音与评测数据 (Priority: P2)

学习者能够查看自己有权访问的评测结果，在提交后 24 小时内跨会话播放录音，并分别删除录音或完整评测。用户删除评测或账户后，相关敏感数据进入可验证的隐藏、学习状态补偿和删除流程。

**Why this priority**: 原始语音是敏感数据，透明的用途、期限、访问和删除能力是启用该功能的前提。

**Independent Test**: 创建两名用户的评测，分别执行查看、临时播放、删除评测和删除账户；验证用户只能访问自己的数据，删除后的链接失效，相关数据在承诺期限内完成清理。

**Acceptance Scenarios**:

1. **Given** 用户拥有一条仍可播放的录音，**When** 用户请求播放，**Then** 每次访问均重新鉴权，返回的临时访问能力有明确有效期且不可形成永久公开链接。
2. **Given** 用户 A 使用用户 B 的录音、评测、练习或作答标识，**When** 发起查看、播放、删除或重试，**Then** 请求被拒绝且不泄露目标资源是否存在。
3. **Given** 用户删除一条评测，**When** 删除请求被接受，**Then** 数据立即从正常用户界面隐藏，录音、派生结果、缓存和关联索引按承诺流程清理，审计记录只保留非敏感最小信息。
4. **Given** 用户删除账户，**When** 账户删除流程执行，**Then** 该用户的录音、评测、临时访问能力和可识别关联一并进入可靠删除流程。

### User Story 6 - 在异常与供应商故障下安全恢复 (Priority: P2)

学习者可以区分浏览器、录音、上传、音频质量、排队和第三方评测错误；可恢复错误提供安全重试，确定性失败不诱导反复提交。运营人员可通过隐私安全的 Trace 定位版本、延迟、成本和写入状态。

**Why this priority**: 第三方语音服务和浏览器音频链路具有天然不稳定性，可靠恢复与可观测性决定功能能否长期运营。

**Independent Test**: 分别注入网络断开、损坏文件、低置信度、无法识别、超时、限流、无效响应、服务异常和取消；验证公开错误分类、重试资格、计费与幂等行为及 Trace 均符合要求。

**Acceptance Scenarios**:

1. **Given** 上传网络中断或超时，**When** 用户重试同一录音，**Then** 系统安全恢复或重新上传，不产生重复评测和重复学习写入。
2. **Given** Provider 超时、限流或暂时不可用，**When** 评测失败，**Then** 返回可恢复的通用错误、建议重试时间和稳定错误码，不暴露内部地址、密钥、原始响应或堆栈。
3. **Given** Provider 返回缺字段、越界分数、相互矛盾状态或无法对齐的词级数据，**When** Schema 与业务校验执行，**Then** 结果不得作为确定性成功展示或写入学习状态，并记录降级原因。
4. **Given** 用户在失败后重试，**When** Provider 已实际受理过原请求，**Then** 预算与费用记账能够识别首次调用与重放，不把同一计费事件重复扣减。

### Edge Cases

- 目标文本为空、超出允许长度、包含不可评测字符、纯标点、非英语内容或危险控制字符。
- 前端提交的目标文本与单词、课程、练习、RAG 来源或 Coach 练习中的权威文本不一致。
- RAG 来源在录音后、提交前被撤销、过期、删除或失去当前用户访问资格。
- 用户在多个标签页同时录音、提交同一音频或以相同幂等键提交不同内容。
- 麦克风权限在录音过程中被操作系统撤销；音频输入设备被拔出或切换。
- 录音只有静音、削波、持续噪声、过低音量、极短爆音，或目标语言完全不匹配。
- 文件扩展名、声明媒体类型、文件签名和可解码内容相互矛盾；文件包含额外载荷或解码资源消耗异常。
- 上传到达大小上限附近、录音时长与容器元数据不一致、时间戳为负数或超出音频时长。
- 目标文本含缩写、连字符、撇号、数字、重复词、同形词、大小写差异或 Unicode 变体。
- 用户漏读开头/结尾、多读词、重复读、交换词序、停顿很长或中途重来。
- Provider 支持总体分数但缺少逐词时间戳、语调或词级分数。
- Provider 返回高总分但逐词错误很多，或返回低置信度却给出看似确定的建议。
- 用户取消恰好发生在上传完成、Provider 受理、结果保存或复习计划更新的边界。
- 用户删除评测时 Provider 仍在处理，或临时播放地址已签发但尚未过期。
- 标准发音不可用、浏览器语音合成音色不同或播放失败；这不得阻止查看评测结果。
- 同一音频在版本未变时重复评测发生显著评分漂移；系统需要标记稳定性风险而非悄然覆盖历史。

## Requirements _(mandatory)_

### Functional Requirements

#### 目标与练习范围

- **FR-001**: 系统 MUST 仅向已通过现有身份认证的用户提供发音录制、提交、结果读取、音频播放、重试和删除能力。
- **FR-002**: 第一阶段 MUST 支持单词朗读、短语朗读和单句跟读，且不接受段落或长篇演讲作为评测目标。
- **FR-003**: 每次评测 MUST 绑定唯一、非空、通过语言与长度校验的目标文本及练习类型。
- **FR-004**: 目标文本 MAY 来自当前单词、已授权课程内容、具有合法且当前有效来源的 RAG 内容、Coach 创建的发音练习或用户手动输入。
- **FR-005**: 对来自既有资源的目标，系统 MUST 根据资源标识在服务端重新取得权威文本，并验证当前用户的资源访问权，不得只信任客户端文本。
- **FR-006**: 手动输入目标 MUST 经过字符、语言、长度和安全校验，且不得被视为已有课程或来源内容。
- **FR-007**: 目标来源、权威文本版本和访问资格 MUST 在提交时再次确认；来源失效的评测不得写入学习闭环。

#### 浏览器录音与状态

- **FR-008**: 录音前 MUST 明确说明麦克风用途、采集范围、第三方处理和录音保存边界，并仅在用户主动操作后请求权限。
- **FR-009**: 界面 MUST 区分未授权、准备录音、正在录音、已完成录音、正在上传、正在分析、评测成功、评测失败、已取消和浏览器不支持状态。
- **FR-010**: 用户 MUST 能开始、停止和取消录音；正式计分录音 MUST NOT 提供暂停或继续，用户需要中断时可停止、取消或重新录制，以保持流利度和停顿评分的连续语义。
- **FR-011**: 录音期间 MUST 展示计时，以及基础音量或波形中的至少一种非内容反馈。
- **FR-012**: 录音结束后用户 MUST 能在提交前本地试听、删除并重新录制。
- **FR-013**: 页面离开、权限撤销、设备中断或取消时 MUST 停止采集、释放麦克风与本地对象资源，并在未保存录音可能丢失时提示用户确认。
- **FR-014**: 系统 MUST 为权限拒绝、设备不存在、录音中断、文件过大、网络断开和服务不可用提供彼此可区分、可操作且不泄密的提示。
- **FR-015**: 第一阶段 MUST 在录制完成后上传完整音频进行评测，不要求实时传输完整音频流或说话过程中实时逐词纠错。
- **FR-016**: 第一阶段 MUST 支持桌面 Chrome、Edge、Firefox、Safari 及移动端 Android Chrome、iOS Safari 的当前与前一个稳定大版本，并在每次录音前独立检测安全上下文、麦克风采集、录音能力和实际编码支持；服务端 MUST 接受 WebM/Opus 与 MP4/AAC，单次音频不得超过 30 秒或 8 MB、不得短于 500 毫秒，目标文本不得超过 30 个英文词或 200 个字符（先达到者为准），上传在 30 秒后超时。

#### 音频安全与质量

- **FR-017**: 客户端 MAY 提前拒绝明显超限或静音音频，但服务端 MUST 独立复核大小、时长、可解码性、真实媒体类型和音频质量。
- **FR-018**: 服务端 MUST 基于文件签名、容器结构与实际解码结果验证音频，不得只信任扩展名或声明的媒体类型。
- **FR-019**: 损坏、伪造、不支持、含异常载荷、解码资源消耗异常或元数据与实际内容矛盾的文件 MUST 在 Provider 调用前被拒绝。
- **FR-020**: 静音、音量过低、有效语音不足或目标语言明显不匹配的音频 MUST 返回音频质量错误或低置信度结果，并引导重录。
- **FR-021**: 上传 MUST 可取消并有明确超时；取消后已接收的临时内容 MUST 进入清理流程，且不再启动新的计费步骤。
- **FR-022**: 系统 MUST 对单次大小、时长、解码工作量、并发上传、用户级请求频率、Provider 调用次数和单次费用设置可审核的硬上限。

#### 可替换评测边界与结构化结果

- **FR-023**: 系统 MUST 定义统一的 `PronunciationAssessmentProvider` 业务边界，使业务流程不依赖任何具体第三方的原始响应。
- **FR-024**: 该边界 MUST 接收权威目标文本、音频和语言信息，并能返回识别文本、整体与分项评分、逐词时间戳、逐词评分与错误类型、结果置信度、请求标识、Provider/模型版本、耗时和费用信息。
- **FR-025**: Provider 结果 MUST 区分成功、低置信度、无法识别、超时、限流、用户取消和服务异常。
- **FR-026**: 第三方响应 MUST 先通过确定性规则转换为统一结构并完成 Schema 与业务一致性校验，原始响应不得直接进入前端、学习记录或 Coach；通用语言模型不得生成或改写核心分数、逐词状态、置信度或学习写入资格，只可在结构化事实冻结后辅助生成非权威总结和练习建议。
- **FR-027**: 统一成功结果 MUST 至少包含 `assessmentId`、`referenceText`、`recognizedText`、`overallScore`、`accuracyScore`、`completenessScore`、`fluencyScore`、可空的 `prosodyScore`、`confidence`、`words`、`summary`、`suggestions`、`nextAction`、`provider` 和 `modelVersion`。
- **FR-028**: 每个逐词项 MUST 至少包含 `word`、`normalizedWord`、可空的 `startMs`、可空的 `endMs`、可空的 `score`、`status` 和可空的 `feedback`。
- **FR-029**: 逐词状态 MUST 限于 `correct`、`mispronounced`、`omitted`、`inserted` 和 `uncertain`，未知第三方状态不得无审查映射为确定性错误。
- **FR-030**: 整体、准确度、完整度、流利度、语调和逐词分数在存在时 MUST 归一到 0–100；0 表示该维度上没有可确认的达成，100 表示在本次目标与评分尺度下达到最高表现，分数仅用于学习反馈。
- **FR-031**: 置信度 MUST 归一到 0–1，表示系统对本次识别与对齐可用于确定性反馈的可信程度，不表示用户英语水平。
- **FR-032**: Provider 不支持的可选维度 MUST 表示为空；整体、准确度、完整度或流利度任一必需维度缺失时，结果不得作为完整成功写入学习状态。
- **FR-033**: `summary` 和 `suggestions` MUST 使用非诊断性语言，解释可观察的朗读表现与可执行练习，不得声称绝对正确或给出专业语言病理诊断。
- **FR-034**: `nextAction` MUST 限于 `retry`、`review` 或 `continue`，并由置信度、音频质量、分数和薄弱项的明确规则得出。
- **FR-035**: 原始第三方请求标识、完整响应和内部错误详情 MUST 与公开结果分离；公开结果不得暴露敏感供应商信息或内部访问地址。

#### 文本规范化与逐词对齐

- **FR-036**: 对齐 MUST 同时保留原始目标文本和规范化词序列，大小写、Unicode 等价形式及不影响读音的标点差异不得单独判错。
- **FR-037**: 缩写、数字、连字符和撇号词 MUST 使用版本化、可测试的展开或分词规则；页面 MUST 能说明实际采用的目标读法。
- **FR-038**: 重复词 MUST 依据目标位置保留独立身份，不能仅按词面合并；交换顺序、多读与重复读 MUST 通过序列对齐表示。
- **FR-039**: 目标词未匹配时 MUST 标记为 `omitted`；识别出但目标中不存在的词 MUST 作为独立 `inserted` 项；无法可靠判定时 MUST 使用 `uncertain`。
- **FR-040**: 时间戳 MUST 满足非负、起点不晚于终点、位于音频时长内且整体顺序合理；不满足时应置空相关时间戳并禁用片段跳转，不得伪造时间。
- **FR-041**: 无效或不完整 Provider 响应 MAY 降级为“无法可靠评测”并保留安全的识别文本，但不得拼装虚假分数、词级错误或确定性建议。

#### 逐词反馈与可访问性

- **FR-042**: 成功页面 MUST 展示目标文本、识别文本、整体评分、准确度、完整度、流利度和语调可用性。
- **FR-043**: 页面 MUST 在原句中标识正确、误读、漏读、插入和不确定词，并提供图例。
- **FR-044**: 词级状态不得只依赖颜色；每种状态 MUST 同时使用文字、图标、形状或辅助技术可读标签中的至少一种。
- **FR-045**: 用户 MUST 能选择词项查看对应反馈；有有效时间戳时 MUST 能跳转至对应录音片段。
- **FR-046**: 用户 MUST 能播放自己的可用录音、播放现有标准发音，并在同一学习上下文中进行对比；标准发音失败不得使评测结果不可用。
- **FR-047**: 页面 MUST 提供重新录制、重试评测、继续学习及 Coach 推荐入口，并明确各操作是否会产生新评测或改变学习记录。
- **FR-048**: 页面 MUST 告知用户本次结果是否写入学习记录、哪些薄弱项发生变化及复习计划如何变化。

#### 学习闭环与幂等性

- **FR-049**: 只有身份、资源归属、权威目标、音频、结构化结果和置信度均通过校验的评测，才可写入现有学习作答记录。
- **FR-050**: 有效评测 MUST 关联当前用户、评测目标、可用时的单词/练习/课程、评测版本及对应学习作答记录。
- **FR-051**: 本规格中的“ExerciseAttempt”业务概念 MUST 对接现有持久化 `LearningAttempt` 闭环；是否更名不得在 Specify 阶段造成第二套平行作答事实来源。
- **FR-052**: 误读和漏读只有在词对齐可靠且置信度达标时 MAY 形成发音薄弱项；插入和不确定项不得自动降低词汇掌握度。
- **FR-053**: 发音表现影响掌握度和复习计划的映射 MUST 版本化、可解释，并与现有 0–5 质量及复习状态语义兼容。
- **FR-054**: 低置信度、失败、取消、来源失效或结构不完整的结果 MUST NOT 自动降低掌握度、创建惩罚性复习或覆盖最近有效作答。
- **FR-055**: 结果保存、薄弱项更新、掌握度变化、复习事件和作答终态 MUST 原子化处理，任何部分失败不得留下不一致状态。
- **FR-056**: 每个评测提交 MUST 有用户范围内的幂等标识与内容指纹；同键同内容返回原结果，同键不同内容拒绝为冲突。
- **FR-057**: 失败重试、页面重连和重复提交 MUST NOT 创建重复作答、复习事件或重复费用扣减；实际发生的新 Provider 调用 MUST 可单独审计。
- **FR-058**: Coach MAY 读取最少必要的结构化评测摘要、薄弱项和复习变化，默认 MUST NOT 读取或接收原始音频。

#### 身份、权限与隐私

- **FR-059**: 用户身份 MUST 仅来自服务端验证后的现有访问令牌上下文；客户端、Prompt、模型或 Provider 给出的 `userId` 不得改变认证主体。
- **FR-060**: 用户只能读取、播放、重试或删除自己的录音、评测、练习、作答和学习状态；跨用户请求 MUST 返回不泄露资源存在性的通用拒绝结果。
- **FR-061**: 评测与单词、课程、练习、RAG 来源和作答的关联 MUST 由业务规则验证，写入掌握度前 MUST 再次确认主体与结果有效性。
- **FR-062**: 音频播放或下载 MUST 每次鉴权；任何临时访问能力 MUST 仅授予当前所有者、有效期不得超过 5 分钟、权限仅限目标音频读取且不可公开索引。
- **FR-063**: 第三方 Provider 只能接收本次评测所需的音频、目标文本、语言及最少技术元数据，不得接收不必要的用户身份、JWT、学习历史或完整画像。
- **FR-064**: 启用 Provider 前 MUST 记录并批准其处理地域与分包策略，并确认其对评测音频、目标文本和派生内容实施零留存且不用于训练；无法满足任一条件时不得启用。
- **FR-065**: 原始录音 MUST NOT 进入普通应用日志、Prompt、Coach 记忆或未经授权的离线评测集。
- **FR-066**: 离线评测音频 MUST 有可证明授权、脱敏状态、来源、用途和使用范围；不得用于声纹识别或年龄、性别、种族、健康、情绪等敏感属性推断。
- **FR-067**: 用户 MUST 能分别删除录音或完整评测：删除录音只移除音频并保留结构化结果和历史学习事件；删除完整评测时 MUST 立即隐藏详细结果，并通过可审计的重新计算或补偿事件消除其派生学习影响，不得静默改写历史；账户注销 MUST 覆盖音频、评测、缓存、临时链接和可识别关联，并有可验证终态。
- **FR-068**: 原始录音在提交前 MUST 仅保存在当前浏览器；提交后 MAY 为短期重试和跨会话回放临时保存，但最长不得超过 24 小时且第一阶段不提供延长或永久保存。用户取消或主动删除后，访问能力 MUST 立即撤销，活动存储与缓存副本 MUST 在 1 小时内清除；原始录音 MUST NOT 进入普通备份，结构化结果按现有学习数据政策保存。

#### 请求治理、失败与可观测性

- **FR-069**: 系统 MUST 在上传前、Provider 调用前和学习写入前分别执行适用的身份、限流、并发、预算、取消与截止时间检查。
- **FR-070**: 用户取消后 MUST 尽可能取消排队和 Provider 请求；无法撤销的外部调用仍须记账，但其迟到结果不得写入学习状态。
- **FR-071**: 失败 MUST 分类为浏览器/权限、录音/设备、上传/网络、音频质量、排队/治理、Provider 和学习写入错误，并提供稳定公开错误码、是否可重试及安全文案。
- **FR-072**: 错误响应和日志 MUST NOT 暴露 JWT、API Key、内部 Prompt、未脱敏对象地址、原始 Provider 响应或服务端堆栈。
- **FR-073**: 每次评测 MUST 记录 Trace ID、脱敏用户标识、练习类型、目标文本长度、音频格式/大小/时长、Provider/模型版本、上传/排队/Provider/总耗时、结果终态、置信度、重试/取消/超时/降级、作答写入、掌握度/复习更新及单次成本。
- **FR-074**: Trace MUST 将一次逻辑提交与其上传尝试、Provider 调用、重试、结果校验和学习写入关联起来，同时保持用户隔离和敏感字段脱敏。
- **FR-075**: Provider、模型、评测规则、Schema、文本规范化、薄弱项映射、预算和价格 MUST 具有可查询版本，以支持重放解释和版本回归。
- **FR-076**: 第一阶段 MUST 仅启用一个主 Provider，且不得将多个 Provider 的分数合并或平均。候选 Provider MUST 支持参考文本英语评测、识别文本、整体/准确度/完整度/流利度评分、逐词状态与时间戳、置信或质量信号、请求标识、模型版本及可核算费用；语调评分 MAY 缺失。项目统一可信度低于 0.60 时 MUST 拒绝为可靠评测，0.60–0.79 时只能显示明确标注的参考反馈且不得改变学习状态，至少 0.80 且其余校验全部通过时才具备写入资格。每用户同时最多处理 1 次评测、最多 6 次/分钟和 120 次/天；每个逻辑评测默认只调用 Provider 1 次，仅在能确认请求未被受理或 Provider 提供可靠幂等保护时 MAY 自动重试 1 次。Provider 单次处理在 30 秒后超时。生产启用前 MUST 批准单次、用户日、系统日和系统月费用上限；价格或价格版本未知、任一费用上限缺失或已超限时 MUST 关闭新调用。

#### AI 评测与发布门槛

- **FR-077**: 项目 MUST 建立版本化的发音评测专项数据集，覆盖标准单词、短语、单句、正确发音、常见误读、漏读、多读/重复、错序、不清晰、低音量、噪声、语速极端、中断、不同麦克风、合理口音、非目标语言、完全不匹配、低置信度、超时、无效响应、越权和文件攻击。
- **FR-078**: 人工音频样本 MUST 记录授权依据、采集或获取来源、可用范围、标注版本和删除约束；未获授权的真实用户录音不得进入数据集。
- **FR-079**: 标注流程 MUST 定义目标文本、词序列、漏读/误读/插入/不确定标签、可接受口音差异、评分尺度、双人复核或争议仲裁及标注者资格。
- **FR-080**: 文件、Schema、范围、权限、幂等、分数边界、时间戳合法性和确定性文本对齐 MUST 使用确定性规则验证。
- **FR-081**: 发音自然度、误读严重度、合理口音、公平性和建议质量 MAY 使用授权人工标注或受控模型辅助评分，但模型辅助结果 MUST 与人工金标区分且不得自我证明。
- **FR-082**: 每个候选版本 MUST 测量识别文本 WER、漏读/误读/插入识别准确率、逐词时间戳误差、评分与人工标注一致性、重复评测稳定性、合理口音间异常评分差异、低质量音频拒绝能力、Schema 通过率、请求成功率、P50/P95 上传及评测耗时、单次成本、无效结果写入比例和跨用户泄露率。
- **FR-083**: 不同 Provider 的比较 MUST 使用同一授权数据集、同一目标文本和可比运行条件，分别报告准确性、延迟、稳定性、能力缺失、隐私条件和成本，不得用合成分数掩盖阻断项。
- **FR-084**: Provider、模型、评测规则、规范化或 Schema 版本变化后 MUST 重跑确定性、安全、质量、公平性、延迟与成本回归，并与已批准基线比较。
- **FR-085**: 越权访问、敏感数据泄露、未授权音频使用、无效结果写入学习状态、取消后错误写入及伪造不支持评分维度 MUST 是零容忍发布阻断项。
- **FR-086**: 尚无可靠基线的质量、延迟、稳定性或成本指标 MUST 标记为“待测量”，不得凭空填写目标；首个候选基线未经批准前不得作为生产启用依据。
- **FR-087**: 合理英语口音 MUST 在评测与人工标注中被视为可接受变体；只有有可验证证据的音素/词级偏差才可标记为错误，口音群体间异常评分差异超出批准门槛时必须阻断发布。
- **FR-088**: 现有 Coach、RAG、单词学习、课程学习和普通练习 MUST 保持原有可用性；发音功能关闭、不可用或 Provider 未批准时，不得产生这些流程的隐式外部调用或明显回归。

### Key Entities _(include if feature involves data)_

- **Pronunciation Assessment（发音评测）**: 一次用户范围内、以明确目标文本和音频为输入的逻辑评测；包含状态、幂等意图、版本、置信度、结构化分数、摘要、费用和学习写入结果。
- **Pronunciation Target（发音目标）**: 要朗读的权威文本及其类型、语言、来源类别、资源标识、来源版本和访问资格；手动输入目标没有伪造的资源归属。
- **Audio Asset（音频资产）**: 一次录音的敏感临时或受限资产；包含真实格式、大小、时长、质量状态、所有者、用途、有效期和删除状态，不包含公开永久地址。
- **Word Assessment（逐词评测）**: 与目标位置或插入位置稳定对齐的词级结果；包含原词、规范化词、时间范围、可空分数、状态和可空反馈。
- **Assessment Provider Record（评测服务记录）**: 外部评测调用的内部审计信息；包含 Provider 请求标识、能力、模型版本、耗时、费用、重试和终态，不直接暴露给普通用户。
- **Learning Attempt（学习作答记录）**: 现有学习闭环中的持久作答事实；有效发音评测通过它关联练习、分数、薄弱项和复习变化。本需求所称 ExerciseAttempt 不另建平行事实来源。
- **Pronunciation Weakness（发音薄弱项）**: 从可靠误读或漏读证据派生的用户学习目标；包含目标词、证据评测、严重度/质量、规则版本和当前复习状态。
- **Assessment Trace（评测 Trace）**: 将上传、排队、Provider、校验、取消、费用与学习写入串联的隐私安全记录，以脱敏主体标识隔离用户。
- **Deletion Request（删除请求）**: 用户对评测、录音或账户数据的删除意图及可验证终态；覆盖用户可见隐藏、活动数据清理、缓存/链接失效和允许保留的最小审计信息。
- **Pronunciation Evaluation Case（发音评测样本）**: 获授权、版本化的离线测试样本及目标文本、人工标签、口音/音频条件、用途范围和预期安全结果。

## Success Criteria _(mandatory)_

### Measurable Outcomes

- **SC-001**: 在批准的支持环境中，至少 95% 的测试用户能在不需要外部帮助的情况下完成“授权—录音—试听—提交—查看逐词反馈”的主流程。
- **SC-002**: 单词、短语和单句三类目标的核心验收场景通过率均为 100%，且所有成功结果都包含整体、准确度、完整度和流利度四项 0–100 分数。
- **SC-003**: 100% 的不支持维度以空值和“不可用”呈现，伪造语调或其他能力缺失分数的比例为 0。
- **SC-004**: 对权限拒绝、无设备、浏览器不支持、录音中断、过短、静音、过大、网络断开、超时、限流和 Provider 异常的验收样本，错误分类准确率为 100%，且每类均给出可执行的下一步。
- **SC-005**: 在批准的基准设备与网络条件下，录音控制状态变化在 300 毫秒内得到可见反馈；从上传完成到用户看到终态的 P95 不超过 15 秒，单次 Provider 处理超过 30 秒的请求 100% 进入超时终态且不写入学习状态。
- **SC-006**: 对包含标点、大小写、缩写和重复词的确定性对齐测试，目标词位置保持正确的比例为 100%；非法时间戳进入可跳转结果的比例为 0。
- **SC-007**: 同一用户、同一幂等意图的重复提交或网络重试造成的重复学习作答、重复复习事件和重复预算扣减比例均为 0。
- **SC-008**: 低置信度、失败、取消、无效 Schema、来源失效和越权结果自动降低掌握度或改变复习计划的比例为 0。
- **SC-009**: 对授权的跨用户安全测试，用户 A 读取、播放、重试、删除或关联用户 B 数据的成功率为 0%，且响应不泄露资源是否存在。
- **SC-010**: 100% 的评测可通过 Trace 关联目标类型、音频元数据、版本、各阶段延迟、终态、置信度、重试/取消、费用和学习写入状态，敏感凭据及未脱敏音频地址出现率为 0。
- **SC-011**: 用户取消或删除录音后 100% 的访问能力立即失效且活动副本在 1 小时内清除；所有正常到期录音在提交后 24 小时内清除，进入普通备份的原始录音比例和删除完成后旧临时链接可用率均为 0。
- **SC-012**: 发音专项数据集的 Schema 通过率为 100%，安全阻断用例通过率为 100%；WER、词级错误识别、时间戳、一致性、稳定性、公平性、拒绝能力、成功率、延迟和成本均形成版本化基线报告。
- **SC-013**: Provider 或模型版本变更时，100% 完成规定回归并与批准基线比较；任一零容忍阻断项失败时，发布通过率为 0。
- **SC-014**: 在可用性研究中，至少 85% 的参与者能正确指出自己至少一个误读或漏读位置，并能从反馈中选择合适的下一步练习。
- **SC-015**: 已保存的有效评测中，100% 向用户说明是否影响学习记录以及具体变化；“评测已成功但写入失败”的情况不会被误示为已更新。
- **SC-016**: 发音能力关闭或不可用时，既有 Coach、RAG、单词、课程和普通练习的核心回归场景通过率为 100%，且不会触发发音 Provider 调用。
- **SC-017**: 排除主动取消、恶意文件和确定性无效音频后，合法评测请求的 Provider 成功率不低于 99%；同一音频在同一版本下重复评测的整体分数最大差异不超过 5 分。
- **SC-018**: 在人工评分匹配的授权口音样本中，不同合理英语口音组之间的平均异常评分差距不超过 5 分；超过该差距或任一零容忍安全项失败时，生产发布通过率为 0。

## Assumptions

- 当前目标仓库继续复用现有访问令牌认证和服务端不可变主体上下文；本功能不引入新的登录方式。
- 现有学习闭环的权威作答实体是 `LearningAttempt`，并通过学习项状态、复习事件和现有复习调度规则记录变化；用户描述中的 ExerciseAttempt 被视为该业务概念而非必须新增的同名实体。
- 现有 Coach 已具备结构化结果校验、幂等请求、取消/重试、版本化 Prompt/模型/预算、费用计量和隐私安全 Trace；本功能复用其治理原则，但不假定所有实现可原样复用。
- 现有 RAG 已具备来源权利、访问范围、引用生命周期和撤销处理；只有当前合法且可访问的来源内容可成为权威发音目标。
- 当前浏览器能力包括标准发音播放和基础语音转文字，但没有可复用的完整录音上传、录音留存或发音评分能力。
- 第一阶段仅处理用户主动录制后提交的英语音频，不包含实时双向语音、实时逐词纠错、多人/课堂、视频、段落或长篇演讲。
- 第一阶段不自研 ASR 或发音评分模型，不强制音素级评分，不训练声纹，也不推断敏感属性。
- 标准发音用于学习对比，不作为本次用户音频的评分来源；标准发音不可用时仍可完成评测结果查看。
- 评测分数是特定目标、音频条件和评测版本下的学习辅助信号，不是绝对语言能力证明或专业诊断。
- 默认最小化原始音频使用并优先持久化结构化结果；浏览器/音频包络、原始录音留存和 Provider 运营门槛已在 2026-09-09 Clarify 会话中确定，具体 Provider 与预算金额仍须在 Plan 阶段依据候选能力、隐私条款和可验证价格选择并批准。
- English Learning MCP Server、多 Agent 工作流、与发音无关的 Coach/RAG 重构、公开分享录音和生产部署均不在本功能第一阶段范围内。

## Out of Scope

- 实时双向语音对话或说话过程中的实时完整音频流评测。
- 多人对话、课堂模式、视频录制、段落或长篇演讲评测。
- 自研语音识别或发音评分模型、强制音素级评分。
- 声纹识别、身份识别或从声音推断年龄、性别、种族、健康、情绪等敏感属性。
- 自动公开、分享或无限期保存所有用户录音。
- English Learning MCP Server、多 Agent 工作流。
- 与发音练习无关的 Coach、RAG、认证、课程或普通练习重构。
- 在 Specify 阶段选择/安装具体 Provider、生成技术方案、拆分任务、修改代码、迁移数据库、上传测试音频、提交或推送代码。

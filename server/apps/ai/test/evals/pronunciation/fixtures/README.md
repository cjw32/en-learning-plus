# Pronunciation evaluation fixtures

`manifest.jsonl` contains only deterministic synthetic descriptors. It contains
no learner recording, voiceprint, real identity, inferred sensitive trait or
downloadable audio path. Each line pins provenance, permitted use, deletion
policy, annotations and all behavior-affecting versions.

Authorized-human manifest status: **empty / not approved**. Human or live cases
must not be added until provenance, evaluation use, revocation/deletion rules,
annotation version, Provider/privacy/model approvals and a positive bounded test
budget have all been recorded. Missing evidence keeps live evaluation closed.
